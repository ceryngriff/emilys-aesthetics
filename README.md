# Emily's Aesthetics

Website for Emily's Aesthetics, an aesthetics clinic in Cardiff offering dermal fillers, skin treatments and body sculpting.

## Features

- Responsive single-page layout with a mobile navigation menu and a header that restyles on scroll
- Treatment cards with expandable "read more" descriptions
- Before-and-after treatment gallery with category filters and a full-screen image viewer
- Client testimonials carousel
- Separate, styled price list page
- Smooth scrolling between sections

## Tech stack

- HTML5 and CSS3
- Vanilla JavaScript
- [Swiper](https://swiperjs.com/) for the gallery and testimonial carousels
- Google Fonts (Playfair Display and Open Sans)

No build step or framework is needed.

## Project structure

```
├── index.html         Main page: treatments, gallery, testimonials, contact
├── price-list.html    Price list
├── style.css          Main styles
├── price-style.css    Price list styles
├── script.js          Navigation, carousels, gallery filtering and viewer
└── *.jpg              Logo and gallery images
```

## Running locally

Open `index.html` in a browser, or serve the folder with any static server.
